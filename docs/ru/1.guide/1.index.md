# Начало работы

> Пишите документацию в Markdown, добавьте один конфиг — и получите быстрый,
> элегантный сайт документации без лишней настройки: dev-сервер, production-сборка,
> поиск и `llms.txt` уже включены.

## Обзор

UnJS Docs — минимальная тема документации и CLI для общего использования в проектах UnJS.

### Стек

Undocs работает на [Nitro](https://nitro.build), [Vite](https://vite.dev), [md4x](https://github.com/unjs/md4x), [rangi](https://github.com/pi0/rangi) и [Unhead](http://unhead.unjs.io/). UI-примитивы — собственные, на базе MIT-лицензии [Reka UI](https://reka-ui.com/).

> UnDocs изначально опирался на [Nuxt](https://nuxt.com/), [Nuxt UI](https://ui.nuxt.com/), [Nuxt Content](https://content.nuxt.com/) ([Comark](https://comark.dev/)), [Vue Router](https://router.vuejs.org/) и другие модули экосистемы Nuxt, такие как [nuxt-llms](https://github.com/nuxt-content/nuxt-llms) и [nuxt-icon](https://github.com/nuxt/icon), которые вдохновили новое поколение undocs.

## Быстрый старт

Создайте проект `docs/` из стартового шаблона:

:pm-x{command="giget gh:unjs/undocs/template docs --install"}

Перейдите в каталог документации `cd docs/`

Запустите dev-сервер:

:pm-run{script="dev"}

Сборка для production:

:pm-run{script="build"}
