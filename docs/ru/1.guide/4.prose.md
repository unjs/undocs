# Prose

> Undocs рендерит обычный Markdown через собственный набор Prose-компонентов с разумными типографическими настройками по умолчанию — достаточно писать Markdown, и всё будет выглядеть хорошо.

## Headings

Используйте `#`–`######` для заголовков. Каждый рендерится с единообразными отступами и якорной ссылкой при наведении.

```md
# Заголовок 1

## Заголовок 2

### Заголовок 3

#### Заголовок 4
```

## Text

Выделяйте текст с помощью **жирного**, _курсива_, ~~зачёркивания~~ и `инлайн-кода`. При необходимости комбинируйте: **_сильный акцент_**.

```md
**жирный**, _курсив_, ~~зачёркивание~~ и `инлайн-код`.
```

## Links

Внутренние и внешние [ссылки](https://unjs.io) оформляются единообразно. Внешние ссылки автоматически открываются в новой вкладке.

```md
Внутренние и внешние [ссылки](https://unjs.io) оформляются единообразно.
```

## Blockquotes

> Цитата рендерится с тонкой левой границей и приглушённым текстом — удобно для callouts и цитирования.

```md
> Цитата рендерится с тонкой левой границей и приглушённым текстом.
```

## Lists

Маркированные, нумерованные и списки задач рендерятся аккуратно:

- Первый пункт
- Второй пункт
  - Вложенный пункт
- Третий пункт

1. Установите пакет
2. Запустите dev-сервер
3. Опубликуйте документацию

- [x] Написать Markdown
- [ ] Проверить рендеринг
- [ ] Задеплоить

## Code

Инлайн `code` и fenced-блоки кода подсвечиваются через [rangi](https://github.com/pi0/rangi):

```ts [example.ts]
export function greet(name: string): string {
  return `Hello, ${name}!`;
}
```
