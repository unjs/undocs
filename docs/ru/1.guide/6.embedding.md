# Встраивание

> Вставьте документацию в iframe и переоформите её для каждого embed через
> URL-фрагмент — без сборки, без конфига и без требования same-origin.

Сайт undocs можно встроить куда угодно обычным `<iframe>`. Чтобы он выглядел
уместно на странице-хосте, добавьте к URL **theme fragment**:

```
https://docs.example.com/guide#~eyJwIjoiIzBlYTVlOSJ9
```

Всё после `#~` — JSON-объект design-токенов в base64url. Страница читает его
до первой отрисовки и применяет как CSS custom properties, поэтому вспышки
темы по умолчанию нет.

Фрагмент выбран намеренно: браузеры никогда не отправляют его на сервер, так
что кэширование, SSR и prerender не затрагиваются, а в отличие от внедрения
stylesheet со стороны родителя это **работает cross-origin**. Странице-хосту
не нужен доступ к document iframe.

## Токены

| Ключ  | CSS property           | Example                           |
| ----- | ---------------------- | --------------------------------- |
| `p`   | `--primary`            | `#0ea5e9`                         |
| `pf`  | `--primary-foreground` | `#ffffff`                         |
| `br`  | `--brand`              | `#0ea5e9`                         |
| `bg`  | `--background`         | `#ffffff`                         |
| `fg`  | `--foreground`         | `#0b0b0c`                         |
| `mu`  | `--muted`              | `#f4f4f5`                         |
| `muf` | `--muted-foreground`   | `#71717a`                         |
| `bd`  | `--border`             | `#e4e4e7`                         |
| `c`   | `--card`               | `#ffffff`                         |
| `r`   | `--radius`             | `0.5rem`                          |
| `w`   | `--ui-container`       | `72rem`                           |
| `f`   | `--font-sans`          | `Inter, ui-sans-serif, system-ui` |

Ещё два ключа — не токены:

- **`d`** — объект с теми же ключами, применяется только в dark mode.
- **`m`** — фиксирует цветовой режим: `"l"` (light) или `"d"` (dark).
  Переключатель light/dark сайта скрывается, когда режим закреплён — иначе
  он ничего бы не делал.

```json
{
  "p": "#0ea5e9",
  "bg": "#ffffff",
  "d": { "p": "#38bdf8", "bg": "#0b0b0c" },
  "m": "l"
}
```

Любое опущенное значение остаётся стилем самого сайта — это слой переопределений,
а не полная тема, поэтому payload из двух ключей — нормальная практика.

## Сборка фрагмента

Закодируйте JSON в base64url и добавьте префикс `#~`. Без зависимостей:

```js
const encode = (theme) =>
  "#~" + btoa(JSON.stringify(theme)).replaceAll("+", "-").replaceAll("/", "_").replace(/=+$/, "");

const src = "https://docs.example.com/guide" + encode({ p: "#0ea5e9", m: "l" });
```

В Node замените `btoa(...)` на `Buffer.from(JSON.stringify(theme)).toString("base64")`.

> [!TIP]
> Работаете в репозитории undocs? `node scripts/embed-theme-url.mjs '{"p":"#0ea5e9"}'`
> печатает фрагмент и **валидирует** payload теми же правилами, что и сайт, —
> опечатка в ключе падает громко, а не молча отбрасывается.
> `--url <base>` печатает полный URL, `--decode <fragment>` читает фрагмент обратно.

## В iframe

```html
<iframe
  src="https://docs.example.com/guide#~eyJwIjoiIzBlYTVlOSIsIm0iOiJsIn0"
  title="Documentation"
  style="width: 100%; height: 100%; border: 0"
></iframe>
```

Payload снимается с URL сразу после чтения, поэтому адрес, который посетитель
может скопировать, остаётся чистым. Обычный якорь работает рядом — поставьте
его перед разделителем:

```
https://docs.example.com/guide#installation~eyJwIjoiIzBlYTVlOSJ9
```

## Ограничения

URL, который может собрать кто угодно, должен уметь только перекрасить страницу,
поэтому фрагмент узкий по задумке:

- Применяются только ключи из таблицы выше. **Неизвестные ключи игнорируются** —
  проверяйте написание: неверный ключ молча отбрасывается, а не падает с ошибкой.
- Значения ограничены 64 символами, весь payload — 2048.
- Значения с `url()`, `image-set()` или `element()` отклоняются — фрагмент
  не может заставить страницу что-то загрузить.
- Значения выставляются через CSSOM, а не как CSS-текст, поэтому сконструированное
  значение не может «вырваться» в произвольные стили.

Это меняет цвета, radius, ширину контейнера и шрифт — но не layout, не скрывает
навигацию и не внедряет контент. Для этого нужна
[своя тема](/ru/guide/custom-theme).
