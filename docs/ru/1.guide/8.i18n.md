# Интернационализация (i18n)

> Многоязычная документация на базе [`@i18n-micro/vue`](https://www.npmjs.com/package/@i18n-micro/vue)
> (то же семейство, что и [nuxt-i18n-micro](https://github.com/s00d/nuxt-i18n-micro)).

Undocs — приложение **Nitro + Vite + Vue** (не Nuxt), поэтому Nuxt-модуль
`nuxt-i18n-micro` напрямую не регистрируется. Вместо этого undocs подключает
Vue-пакет `@i18n-micro/vue` с кастомным адаптером под собственный роутер undocs.

i18n — **opt-in**: без блока `i18n.locales` сайт остаётся одноязычным
(только `docs.lang` для `<html lang>`).

## Включение i18n

В `.config/docs.yaml`:

```yaml
lang: en
url: https://example.com # enables hreflang / canonical / og:locale
i18n:
  defaultLocale: en
  strategy: prefix_except_default
  locales:
    - code: en
      iso: en-US
      displayName: English
    - code: ru
      iso: ru-RU
      displayName: Русский
      landing:
        heroTitle: "Документация UnDocs"
      # banner / versions / navigation patch optional
```

## Структура контента

| Файлы                  | URL                         |
| ---------------------- | --------------------------- |
| `docs/1.guide/….md`    | `/guide/…` (default locale) |
| `docs/ru/1.guide/….md` | `/ru/guide/…`               |

## UI chrome + `locales/`

Строки интерфейса (поиск, TOC, surround, copy, …) живут в i18n-бакете маршрута
**`index`**. Page-scoped JSON (`docs/locales/pages/<a>/<b>/{code}.json` → маршрут
`a-b`) мержится **поверх** этих корневых строк. Если для текущего пути нет
page-dict, undocs оставляет `setRoute('index')`, чтобы chrome `$t` не пропадал.

Переопределяйте и расширяйте корневые строки через `docs/locales/{code}.json`.

В Markdown:

```md
:i18n{keypath="demo.intro"}
```

Демо: :i18n{keypath="demo.intro"}

## SEO

Когда задан `docs.url` (→ `site.url`), undocs отдаёт canonical, hreflang
(+ `x-default`) и `og:locale` через `useLocaleHead`. Отключение на странице:

```yaml
---
i18n:
  disableMeta: true
---
```

Это пропускает locale alternates/og-теги, оставляя `<html lang>`.

## Поиск

Поиск (палитра + WebMCP `search_docs`) фильтруется по **текущей локали**.

## Переключатель языка

Geist-дропдаун с настоящими ссылками. Если эквивалентной страницы в целевой
локали нет, ссылка ведёт на home этой локали (`/` или `/ru`).
