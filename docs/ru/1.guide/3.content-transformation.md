## Auto Code Groups

Если блоки кода идут сразу друг за другом, они будут сгруппированы компонентом `code-group`.

````md
```json [package.json]
{
  "scripts": {
    "dev": "undocs dev"
  }
}
```

```ts [server/api/hello.get.ts]
export default defineEventHandler(() => {
  return {
    hello: "world",
  };
});
```

```html [index.html]
<template>
  <div>
    <h1>Добро пожаловать на главную</h1>
  </div>
</template>
```
````

## Steps

Генерируйте шаги с помощью обычных нумерованных списков markdown!

> [!IMPORTANT]
> Чтобы компонент сгенерировался, хотя бы в одном пункте списка должно быть содержимое. Список не может быть дочерним элементом другого компонента, а любой вложенный в пункт markdown-контент должен иметь отступ минимум в 2 таба, чтобы считаться дочерним.

```md
1. Установите пакет

   ::note
   Обратите внимание: шаги работают только с нумерованными списками и не работают во вложенных компонентах.
   ::

   :pm-install{name="undocs"}

2. Запустите dev-сервер

   :pm-run{script="undocs"}

3. Готово ✅
```

1. Установите пакет

   ::note
   Обратите внимание: шаги работают только с нумерованными списками и не работают во вложенных компонентах.
   ::

   :pm-install{name="undocs"}

2. Запустите dev-сервер

## Config References

Генерируйте аккуратные справочники по конфигурации — просто из markdown!

> [!TIP]
> Если вы используете [automd:jsdocs](https://automd.unjs.io/generators/jsdocs), можно ссылаться на файл схемы напрямую! Пример — на странице [конфигурации](/ru/config).
