## Cross-origin isolation

Страницы, которым нужны `SharedArrayBuffer` или wasm-потоки — встроенный
SQLite, демо FFmpeg, Rust playground, всё, что тянется к `Atomics.wait` —
получают эти API только на
[cross-origin isolated](https://developer.mozilla.org/en-US/docs/Web/API/Window/crossOriginIsolated)
странице. Isolation включается явно и по умолчанию выключен:

```yaml
crossOriginIsolation: true
```

С включённой опцией каждый ответ отдаёт:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: credentialless
```

Нужны оба заголовка — одного COOP недостаточно. Они применяются через
Nitro route rules, поэтому `undocs dev` и production-сборка ведут себя одинаково.

`credentialless` (то, что означает `true`) отправляет cross-origin no-cors
запросы к субресурсам **без credentials**, поэтому сторонние картинки, шрифты
и скрипты продолжают загружаться независимо от того, opt-in'ятся ли хосты.

`require-corp` — более строгий вариант, безопасен только когда каждый
cross-origin asset документации отдаёт `Cross-Origin-Resource-Policy` (или
загружается с CORS) — иначе ресурс блокируется:

```yaml
crossOriginIsolation: require-corp
```

::note
При любом значении **cross-origin iframe** должен сам отдавать
`Cross-Origin-Embedder-Policy`, иначе не загрузится. После включения isolation
проверьте встроенные playground'и, видео и сторонние виджеты — это свойство
самого isolation, а не выбранного значения.
::

#### `api`

- **Type**: `string`

The URL to the sponsors JSON API.

### `themeColor`

- **Type**: `string`

The accent color of the documentation site. Defaults to `mono`.

Accepts `mono` (no accent — links and active navigation read in body color, the monochrome default), a Geist hue (`blue`, `red`, `amber`, `green`, `teal`, `purple`, `pink`), a Tailwind palette name that maps onto the nearest Geist hue (`violet` -> purple, `cyan` -> teal, `rose` -> red, ...), a neutral name (`gray`, `slate`, `zinc`, `neutral`, `stone`) as a synonym for `mono`, or any CSS color.

It tints links, active navigation, icons, and the landing glow, and is used for the `theme-color` meta tag. Buttons and other solid fills stay monochrome, as they are in Geist.

### `url`

- **Type**: `string`

The URL of the documentation site.

### `versions`

- **Type**: `array`

The versions of the documentation site.
