# Internationalization (i18n)

> Multilingual documentation powered by [`@i18n-micro/vue`](https://www.npmjs.com/package/@i18n-micro/vue)
> (same family as [nuxt-i18n-micro](https://github.com/s00d/nuxt-i18n-micro)).

Undocs is a **Nitro + Vite + Vue** app (not Nuxt), so the Nuxt module
`nuxt-i18n-micro` is not registered directly. Instead undocs wires the Vue
package `@i18n-micro/vue` with a custom adapter for undocs' own router.

i18n is **opt-in**: without an `i18n.locales` block the site stays monolingual
(only `docs.lang` for `<html lang>`).

## Enable i18n

In `.config/docs.yaml`:

```yaml
lang: en
url: https://example.com # enables hreflang / canonical / og:locale
i18n:
  defaultLocale: en
  strategy: prefix_except_default
  locales:
    - code: en
      iso: en-US
      displayName: English
    - code: ru
      iso: ru-RU
      displayName: Русский
      landing:
        heroTitle: "Документация UnDocs"
      # banner / versions / navigation patch optional
```

## Content layout

| Files                  | URL                         |
| ---------------------- | --------------------------- |
| `docs/1.guide/….md`    | `/guide/…` (default locale) |
| `docs/ru/1.guide/….md` | `/ru/guide/…`               |

## UI chrome + `locales/`

Shipped UI strings (search, TOC, surround, copy, …) live under the i18n **`index`**
route bucket. Page-scoped JSON (`docs/locales/pages/<a>/<b>/{code}.json` → route
`a-b`) is merged **on top of** those root strings. If no page dict exists for the
current path, undocs keeps `setRoute('index')` so chrome `$t` never disappears.

Override/extend root strings with `docs/locales/{code}.json`.

In Markdown:

```md
:i18n{keypath="demo.intro"}
```

Demo: :i18n{keypath="demo.intro"}

## SEO

When `docs.url` (→ `site.url`) is set, undocs emits canonical, hreflang
(+ `x-default`), and `og:locale` via `useLocaleHead`. Opt out per page:

```yaml
---
i18n:
  disableMeta: true
---
```

That skips locale alternates/og tags while keeping `<html lang>`.

## Search

Search (palette + WebMCP `search_docs`) is filtered to the **current locale**.

## Language switcher

Geist dropdown with real links. If the equivalent page is missing in the target
locale, the link falls back to that locale’s home (`/` or `/ru`).
